---
title: "Get an execution"
description: "GET /v1/executions/:id for input, connection context, status, output, or normalized error."
---

```bash
curl "$EYEBALL_EXECUTOR_URL/v1/executions/exe_01JZ6WA0Q73ZQ5B51SRYB6M4Z8" \
  -H "Authorization: Bearer $EYEBALL_API_KEY"
```

The detail route returns the project-scoped execution, including the canonical input and connection context retained by the engine:

```json
{
  "executionId": "exe_01JZ6WA0Q73ZQ5B51SRYB6M4Z8",
  "tool": "gmail.search_emails",
  "toolVersion": "1.0.0",
  "catalogVersion": "1.1",
  "status": "succeeded",
  "userId": "demo_user",
  "createdAt": "2026-07-17T12:00:00.000Z",
  "projectId": "proj_docs",
  "mode": "sync",
  "input": {
    "query": "reservation",
    "pageSize": 5
  },
  "output": {
    "emails": [],
    "nextPageToken": "page_2"
  },
  "latencyMs": 31
}
```

A missing or cross-project ID returns `not_found`. Poll until `succeeded` or `failed`; terminal records do not change.
