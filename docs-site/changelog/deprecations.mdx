There are no deprecated APIs in the `0.2.0` source cut. No npm release is claimed.

## Not implemented, not deprecated

- The current AI SDK callback does not propagate a stable framework call ID, so mutation use is not launch-safe.
- MCP Tasks are opt-in and experimental, and stock SSE replay is not implemented. Cancellation is supported, but work already dispatched to a provider is best effort and external side effects may still complete.
- Hosted OAuth routes exist in private cloud source but are not deployed or live-provider certified.

These are gaps, not old APIs that callers should continue using.

When a future deprecation is introduced, this page will name the replacement, compatibility window, affected versions, migration steps, and removal version.
