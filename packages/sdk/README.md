# `@eyeball/sdk`

TypeScript client for Eyeball tool discovery, execution, files, webhooks, triggers, and voice-agent APIs.

This package is ESM-only and requires Node.js 20 or newer. It depends on `@eyeball/core` and `@eyeball/catalog` and exports its public API from the package root.

Install from npm with `npm install @eyeball/sdk`.

See the [Eyeball repository](https://github.com/Kastarter/eyeball) for documentation and release status.
