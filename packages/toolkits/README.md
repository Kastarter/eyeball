# `@eyeball/toolkits`

Provider adapters that translate Eyeball's canonical tool contracts into provider-specific requests and normalized results.

This package is ESM-only and requires Node.js 20 or newer. It depends on `@eyeball/core` and exports its public API from the package root.

The publishing pipeline is ready, but access to the `@eyeball` npm organization is still pending. Until the first npm release is explicitly announced, consume this package from the Eyeball workspace.

See the [Eyeball repository](https://github.com/eyeball-ai/eyeball) for documentation and release status.
