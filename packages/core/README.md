# `@eyeball/core`

Canonical contracts, JSON schemas, credentials, execution seams, converters, and local-vault primitives for Eyeball.

This package is ESM-only and requires Node.js 20 or newer. Its public API is exported from the package root.

Install from npm with `npm install @eyeball/core`.

See the [Eyeball repository](https://github.com/Kastarter/eyeball) for documentation and release status.
