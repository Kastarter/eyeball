# `@eyeball/catalog`

Deterministic toolkit manifests, canonical capability schemas, authentication metadata, versioned baselines, and tool discovery for Eyeball.

This package is ESM-only and requires Node.js 20 or newer. It depends on `@eyeball/core` and exports its public API from the package root.

Install from npm with `npm install @eyeball/catalog`.

See the [Eyeball repository](https://github.com/Kastarter/eyeball) for documentation and release status.
